# Chrono Chess 5D (5D Chess with Multiverse Time Travel for Android & PC)

Полнофункциональный аналог и порт **5D Chess with Multiverse Time Travel** на движке **Godot 4** (GDScript), оптимизированный для сенсорных экранов Android и поддерживающий ПК.

---

## 🎮 Возможности игры

1. **Полная 4D/5D механика:**
   - Координаты `(X, Y, T, L)`: доска, полуход во времени и номер параллельной линии времени.
   - Прыжки фигур во времени (T) и в параллельные миры (L).
   - Автоматическое создание новых временных линий при ходе в прошлое.
   - Механика «настоящего» (Present) и обязательных досок (золотая рамка) / опциональных досок (зеленая рамка).
   - Ограничение активности линий (неактивные затемняются, если соперник отстает по числу созданных веток).
   - Шах и мат сквозь время (проверка угроз королям из будущего и из прошлого с индикацией красными стрелками).
   - Превращение пешек, рокировка, взятие на проходе.

2. **Все ключевые фигуры:**
   - Пешка, Конь, Слон, Ладья, Ферзь, Король.
   - **Единорог (Unicorn)**: триагональ (движение сразу по 3 осям).
   - **Дракон (Dragon)**: квадриагональ (движение сразу по 4 осям).
   - **Принцесса (Princess)**: гибрид ладьи и слона (1 или 2 оси).

3. **Режимы игры:**
   - 🤖 **Против ИИ**: три уровня сложности (Лёгкий, Средний, Сложный), фоновые вычисления в отдельном потоке (UI не зависает).
   - 👥 **Вдвоём на одном устройстве (Hotseat)**: удобный просмотр и фокус на активных досках.
   - 🌐 **Мультиплеер (LAN / Wi-Fi / по IP)**: прямое подключение между двумя смартфонами или ПК и смартфоном по порту 7575.

4. **Варианты стартовой расстановки:**
   - Классика 8×8
   - Ход ноль (Turn Zero — доска в прошлом для черных)
   - Принцессы
   - Единороги и драконы
   - Малая 6×6
   - Мини 5×5 (идеально для быстрого обучения)
   - Короли и пешки

5. **Полностью независимое визуальное и звуковое оформление:**
   - Собственная векторная процедурная графика фигур (PieceArt) без зависимости от чужих ассетов.
   - Процедурный синтезатор звуков (Sfx) в реальном времени через AudioStreamWAV (не требует внешних аудиофайлов).
   - Адаптивное сенсорное управление: жесты масштабирования (pinch-to-zoom), панорамирование (drag), автоцентрирование на «настоящем».

## 📁 Структура проекта

```text
├── project.godot               # Конфигурация проекта Godot 4
├── export_presets.cfg          # Пресет экспорта под Android (ARM64, permissions)
├── icon.svg                    # Иконка игры
├── scenes/
│   └── main.tscn               # Стартовая сцена
└── scripts/
    ├── main.gd                 # Главный контроллер переключения меню/игры
    ├── engine/
    │   ├── game_state.gd       # 5D-движок правил, линий, генерации ходов и проверки мата
    │   ├── chess_ai.gd         # Шахматный ИИ с оценкой позиций и дерева решений
    │   └── variants.gd         # Режимы и стартовые позиции
    ├── net/
    │   └── net.gd              # Высокоуровневый мультиплеер (ENet RPC)
    └── ui/
        ├── multiverse_view.gd  # Отрисовка таймлайнов, досок, стрелок и жестов
        ├── game_screen.gd      # Игровой экран партии, HUD и управление
        ├── menu_screen.gd      # Меню выбора режимов, настроек и правил
        ├── piece_art.gd        # Векторные процедурные фигуры
        ├── piece_button.gd     # Кнопка для диалога превращения пешки
        └── sfx.gd              # Синтезатор звуковых эффектов
```

## 🚀 Как запустить и протестировать на ПК

1. Скачайте **Godot Engine 4** (рекомендуется версия 4.2 или 4.3 Standard): [godotengine.org](https://godotengine.org/download)
2. Запустите Godot, нажмите **Import** («Импортировать») и укажите файл:
   `c:\Users\Zlo1Desu\Desktop\5d chess\project.godot`
3. Нажмите кнопку **Run Project** (F5) — откроется меню игры.

## 📱 Как собрать APK для Android

1. В Godot Engine откройте **Editor -> Editor Settings -> Export -> Android**:
   - Укажите путь к **Android SDK** (например, `C:/Users/<Username>/AppData/Local/Android/Sdk`).
   - Укажите путь к **Java OpenJDK** (JDK 17).
   - Укажите путь к `debug.keystore` (генерируется командой `keytool` или создается автоматически Android Studio).
2. Установите экспортные шаблоны Godot: **Editor -> Manage Export Templates -> Download and Install**.
3. Откройте **Project -> Export...**:
   - Выберите пресет **Android**.
   - Нажмите **Export Project...** и сохраните `chrono-chess-5d.apk`.
4. Перенесите APK на телефон и установите (или запустите прямо на подключенном смартфоне по USB с помощью иконки Android в верхнем правом углу редактора Godot — «One-Click Deploy»).
